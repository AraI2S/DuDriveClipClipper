百度网盘剪贴板清理 v1.0.0
==========================

用途
----
复制包含百度网盘分享链接的文字，脚本自动把剪贴板替换为简洁链接。
无需手动清理标题、说明、会员签名；如文字提供提取码但网址未带 pwd，脚本会自动补上。

示例 1
原文：链接: https://pan.baidu.com/s/19xSckhDr5Fn4mZXUjHMqww?pwd=ABCD 提取码: ABCD
结果：pan.baidu.com/s/19xSckhDr5Fn4mZXUjHMqww?pwd=ABCD

示例 2
原文：链接: https://pan.baidu.com/s/1SILi2vdp1fWqd1vQAMjZBA 提取码: ABCD
结果：pan.baidu.com/s/1SILi2vdp1fWqd1vQAMjZBA?pwd=ABCD

安装与运行
----------
1. 解压整个文件夹，放到你喜欢的位置。保留 Start.vbs 和 Main.ps1 在同一目录。
2. 双击 Start.vbs。没有命令行窗口；右下角系统托盘会出现 Windows 默认蓝色“i”图标。
3. 现在复制百度网盘链接或完整分享文本，再 Ctrl+V，即可粘贴干净的链接。
4. 若右下角没看到图标，点任务栏右侧“^”展开隐藏的托盘图标。

托盘图标右键菜单
----------------
- 暂停自动清理：开关自动监听，不影响正常复制；再次点击继续。
- 立即清理当前剪贴板：手动尝试清理一次（暂停时也有效）。
- 退出：彻底停止监听与后台进程。

重复双击 Start.vbs 不会启动第二个常驻实例。
开始运行时，也会尝试清理剪贴板中已存在的分享文本。
没有开机自启，也没有修改注册表；退出后不会继续监听。

可选：开机自动启动
------------------
按 Win+R，输入 shell:startup 并回车。
对 Start.vbs 创建“快捷方式”，将快捷方式放到打开的“启动”文件夹。
如需取消，删除这一快捷方式即可。

处理范围与安全规则
------------------
- 仅匹配 pan.baidu.com/s/1... 格式的百度网盘分享链接。可带 https://、http:// 或 www.。
- 最终输出统一删除 http(s):// 与 www.，保留原分享 ID；只保留 pwd 参数（如有）。
- 若链接本身有 ?pwd=ABCD，优先使用网址中的密码。
- 若网址未带密码，从“提取码: ABCD”“提取码：ABCD”以及“访问码”“访问密码”“提取密码”中提取（支持 4-8 位英文字母或数字）。
- 若整段文本有多个网盘链接、互相冲突的密码、未知格式的现有 pwd 参数：原样保留，避免丢失重要信息。
- 普通文字、其它网盘、图片与非文本剪贴板内容均不处理。
- 已是目标规范的文本不会再次写入剪贴板，避免死循环。
- 为保持输出纯净，重写剪贴板时只写纯文本；原先富文本/HTML 格式不会保留。
- 依赖剪贴板事件通知，而非持续轮询；部分软件大量操作剪贴板时可能出现短暂延迟。
- 复制后立刻（几十毫秒内）粘贴，有小概率快于监听处理完成。正常重试粘贴即可。
- 没有网络请求、上传、数据收集或权限提升。脚本只在本机访问剪贴板。
- 当前仅覆盖 /s/ 分享格式，其他百度网盘网址格式不会被推断转换。

系统要求与测试
--------------
Windows 10/11，系统自带 Windows PowerShell 5.1 与 .NET Framework 4.x；使用 Windows Script Host 启动。
通过双击 SelfTest.cmd 执行 14 组离线逻辑用例，窗口会逐项显示 PASS/FAIL。
这些是代码级规则测试。是否能收到系统剪贴板事件、图标是否显示，仍需要在真实 Windows 电脑上验收。
建议实机验证：
  A. 正常复制上面的两段分享内容，粘贴的结果与示例完全相同。
  B. 复制普通文字，保持不变。
  C. 右键托盘图标暂停，再复制分享文字，应保持原样；恢复后再次复制，应自动处理。
  D. 快速连续复制不同文本，确认最后一份内容不被前一份覆盖。
  E. 再双击 Start.vbs，确认系统托盘没有新增第二个实例。
  F. 退出托盘程序后，复制分享文字不会被清理。

排查
----
- 无托盘图标：先检查隐藏的系统托盘；确认 Windows Script Host/PowerShell 未被企业安全策略阻止。
- 提示无法运行 PowerShell：可在终端执行 SelfTest.cmd 查看错误；脚本仅对自身启动进程使用 ExecutionPolicy Bypass，不修改系统策略。
- 剪贴板没有变化：请检查分享网址是否为 /s/1...，有无两个链接/提取码冲突，或程序是否已暂停。
- 如果 Windows 电脑上出现错误，请把报错文字或 SelfTest.cmd 的输出发回，以便针对性修复。
